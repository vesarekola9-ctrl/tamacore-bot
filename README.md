# TamaCore Bot 🐰

TamaCore is a Python-based GDevelop game generation project with an additional standalone playable HTML browser edition. These are **different outputs**; the browser game is generated by `src/tamacore/factory_v3_1/playable_browser.py`, while the factory builds GDevelop project data.

## Generate a game

Install the Python project first (Python 3.10+):

```bash
python -m pip install -e .
python -m tamacore.cli ai-make-game --out-pack assets/packs/ai_game_1 --template templates/gdevelop_template --out-game ../tamacore-game --export-out exports --bundle-out release_bundle --shop-count 5 --foods 5 --cosmetics 5 --with-demo-layout
```

The full AI generation pipeline is under development. Generated GDevelop projects have **not** yet been verified end-to-end.

## Check the code

Run the Python regression tests from the repository root:

```bash
PYTHONPATH=src python -m unittest discover -s tests -p 'test_*.py' -v
```

On Windows PowerShell, set the environment variable with `$env:PYTHONPATH='src'` before running the same Python test command. Python compilation and tests run in `.github/workflows/python-tests.yml` on pushes and pull requests. The browser export smoke and JavaScript syntax check run in `.github/workflows/check-game.yml` when the browser generator changes. These checks do not replace real browser interaction testing.
